零后端聊天平台

一个纯前端 + 无服务器数据库的真实项目 —— NFLSHC Chat

技术分享 · 2026

一个真实的故事

南外淮安分校 202401 班的同学们，想要一个属于自己的聊天平台：

  • 多聊天室、消息实时收发、引用回复、置顶
  • 用户等级、主题切换、数据仪表盘
  • 内置 AI 助手（HZYAI）、全局搜索

但问题来了 —— 没人想租一台服务器。

核心问题

❌ 传统做法 买云服务器 + 装数据库 + 写后端 API + 运维监控。成本高、门槛高。
✅ 我们的选择 浏览器直接读写云端数据库，零服务器、零运维。

答案：把数据库搬上 Cloudflare D1，用 Cloudflare Workers 做网关。

架构全景

┌───────────────┐ HTTPS ┌────────────────────┐ │ 浏览器前端 │ ───────────────▶ │ Cloudflare Workers │ │ (纯 HTML/JS) │ │ worker gateway │ └───────────────┘ └─────────┬──────────┘ │ SQL ▼ ┌────────────────────┐ │ Cloudflare D1 │ │ (Serverless SQLite)│ └────────────────────┘

前端零框架；网关托管在 Cloudflare 边缘节点；数据存在 D1 无服务器数据库。

Cloudflare D1 即数据库

  • D1 是 Cloudflare 的无服务器 SQLite，按请求计费，几乎零成本
  • 不同业务类型（label）对应不同的数据表：chatmessage / user / room / role …
  • 每条数据是一行记录，业务字段以 JSON 形式存储
// 一条聊天消息（D1 中 label: chatmessage 的记录） { "id": "msg_abc123", "roomId": "room_general", "sender": "黄兴", "content": "大家好！", "timestamp": "2026-08-09T10:00:00Z" }

Cloudflare Workers 网关

  • Worker 暴露 REST 风格接口（/api/messages、/api/legacy/issues 等）
  • 天然CORS 友好，浏览器可直接调用，无需自建代理
  • 在网关层隐藏数据库凭证，前端只持有一个访问令牌（Token）
  • 兼容层让旧前端逻辑无需大改即可从 GitHub Issues 平滑迁移到 D1

实战：一条聊天消息的生命周期

1. 用户在 chat.html 输入并点击发送 2. 前端 POST /api/messages → Worker 3. Worker 写入 D1 表 messages (raw_json 列) 4. Worker 同步写入 legacy issues(chatmessage) 供统计 5. 其他客户端轮询 / 拉取最新消息并渲染

发送与统计解耦：实时消息走 /api/messages，群聊统计从 legacy 层聚合。

用户认证与权限

  • 通过访问令牌（Token）识别用户，写入 D1 的 user 表
  • 等级系统基于活跃度：等级 = ⌊√(XP/10)⌋ + 1
  • 四色等级样式：绿 → 蓝 → 紫 → 金，激励持续参与

聊天室 · 角色 · AI 助手

💬 多聊天室每个房间一条 D1 记录，支持引用、置顶、@提醒、代码高亮。
🎭 角色系统自定义人设，提示词存 D1，可配置 RAG 知识库。
🤖 HZYAI接入多模型（含 Cloudflare Workers AI），复用角色知识库。

数据仪表盘

  • 30 天消息趋势、24 小时活跃分布、词云、Top10 发言排行
  • 全部由 Chart.js 驱动，数据直接来自 D1 聚合查询
  • 管理员后台 admin.html 实时读取群聊统计

多端支持

🌐 Web任意浏览器，PWA 可安装到桌面/手机。
🖥️ WindowsNSIS 安装版 / 便携版（Electron 封装）。
📱 AndroidAPK（标准版 / Pro 版）。
💬 微信小程序同一套后端，多端畅聊。

部署：成本为零

  • 前端托管在 Cloudflare Pages（或 Workers Assets），全球 CDN
  • 网关部署为 Cloudflare Worker，一条 wrangler deploy 上线
  • 数据库 D1 随用随付，小规模近乎免费
  • 源码开源在 github.com/user-henry/nflshcchat（MIT）

踩过的坑

  • CORS / 限流：早期直连第三方 API 触发 Cloudflare 1010，移到 Worker 网关后解决
  • Schema 不一致：部分表缺少 raw_json 列，写入被静默吞掉 → 按表分支处理
  • 统计丢数据：文本消息只写实时表、未写 legacy 层，导致群聊统计缺失 → 发送时双写

未来：更多 AI 能力

  • 接入 Cloudflare Workers AI（Llama / Qwen / Gemma 等）做实时对话
  • 多模态：文生图、文生视频、语音识别与合成
  • RAG 知识库持续扩充，让 HZYAI 更懂班级社区

结语

用 Cloudflare D1 + Workers，一个学生项目也能拥有：

零服务器 · 零数据库运维 · 近乎零成本 · 功能一应俱全
